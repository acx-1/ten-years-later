```

┌─────────────────────────────────────────────────────────┐
│                     后端技术栈                            │

│ 环境变量     │ dotenv (配置管理)                           │
└─────────────┴───────────────────────────────────────────┘
```

## 三、认证架构

```
┌─────────────────────────────────────────────────────────────┐
│                      认证流程                                │
│                                                             │
│   ┌──────────┐         ┌──────────┐         ┌──────────┐  │
│   │  用户输入 │         │ 后端验证  │         │  会话管理 │  │
│   │用户名密码 │ ──────▶ │ bcrypt   │ ──────▶ │  JWT Token│  │
│   └──────────┘         │ 密码比对  │         └─────┬────┘  │
│                        └──────────┘               │       │
│                                                     │       │
│                              ┌──────────────────────┘       │
│                              │                              │
│                              ▼                              │
│                    ┌──────────────────┐                     │
│                    │   HTTP-Only      │                     │
│                    │   Secure Cookie  │                     │
│                    │   (kimi_sid)     │                     │
│                    └────────┬─────────┘                     │
│                             │                               │
│              ┌──────────────┼──────────────┐               │
│              │              │              │               │
│              ▼              ▼              ▼               │
│        ┌──────────┐ ┌──────────┐ ┌──────────────┐        │
│        │每次请求   │ │ 自动发送  │ │ 服务端验证    │        │
│        │携带Cookie│ │ 到 /api/  │ │ JWT 签名 +   │        │
│        │         │ │ trpc     │ │ 过期时间检查 │        │
│        └──────────┘ └──────────┘ └──────────────┘        │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    密码安全处理                              │
│                                                             │
│  明文密码 ──▶ bcrypt.hash(password, 12)                     │
│                                                             │
│  生成: $2a$12$[22字符salt][31字符hash]                        │
│  示例: $2a$12$LQv3c1yqBWVHxkd0LHAkCOYz6TtxMQJqhN8/...       │
│                                                             │
│  验证: bcrypt.compare(inputPassword, storedHash)            │
│                                                             │
│  安全特性:                                                  │
│    ✓ 自动盐值 (每次哈希结果不同)                             │
│    ✓ 成本因子 12 (约 250ms 哈希时间)                         │
│    ✓ 抗彩虹表攻击                                           │
│    ✓ 抗时序攻击                                             │
└─────────────────────────────────────────────────────────────┘
```
